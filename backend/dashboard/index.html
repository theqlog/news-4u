How these counts work

Download and parsing run together. Awaiting extraction is a stored backlog, not a count of articles currently running. Counts reflect articles currently retained in the database, not lifetime ingestion. Missing content includes null, blank, and literal “None” values. Disabled extraction takes precedence over retry limits.
